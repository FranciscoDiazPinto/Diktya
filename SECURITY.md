# Política de seguridad

Notifica las vulnerabilidades de forma privada mediante **Security → Report a vulnerability** en este repositorio. No abras un issue público ni incluyas datos reales, credenciales o información del cliente.

Indica la versión o commit, los pasos para reproducir y el impacto. El equipo confirma la recepción en un plazo de cinco días hábiles y coordina la corrección antes de cualquier divulgación.

Alcance: el código de `netbot/`. La infraestructura del cliente queda fuera y no debe probarse sin su autorización escrita.
